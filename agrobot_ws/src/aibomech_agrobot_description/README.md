# aibomech_agrobot_description

The robot model: kinematics, meshes, masses, joint limits and calibration. Every other package reads the robot from here.

| File | Content |
|---|---|
| `urdf/agrobot.urdf.xacro` | top-level model; arguments select the carrier, camera and hardware back-end |
| `urdf/arm.xacro` | the 4-axis arm, gripper and tool frames (`flange`, `tool0`, `tcp`, `tcp_center`) |
| `urdf/platform.xacro` | carriers: `rail_trolley` (default), `pedestal`, `table` |
| `urdf/camera.xacro` | RGB-D camera on its mast |
| `urdf/agrobot.ros2_control.xacro` | joint interfaces and the hardware plugin (`mock`, `gz` or `real`) |
| `urdf/agrobot.gazebo.xacro` | Gazebo plugins (controllers, camera sensor) |
| `config/joint_limits.yaml` | position, velocity and effort limits, the single source for URDF, controllers and tasks |
| `config/arm_physical.yaml` | masses, inertias and collision boxes, generated by `tools/compute_physical_params.py` from the CAD data in `cad/` |
| `config/hardware_calibration.yaml` | joint offsets and directions of the real robot |
| `config/initial_positions.yaml` | start pose |

View the model with joint sliders:

```bash
ros2 launch aibomech_agrobot_description view_robot.launch.py            # platform:=pedestal|table
```
