# Learning material

`image_segmentation_tutorial.ipynb` is a guided PyTorch exercise on image segmentation (segmentation-models-pytorch with an EfficientNet encoder, trained on a public human-segmentation dataset). It follows an online guided project and several cells are still empty.

It is kept as a starting point for replacing the colour thresholds of the crop detector (`agrobot_ws/src/aibomech_agrobot_tasks/aibomech_agrobot_tasks/perception.py`, function `segment()`) with a learned model. It is not used by the robot software.
